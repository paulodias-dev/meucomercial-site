# M18 — Site público na RC 1.0: contratação sem caixa duplicado

18/11/2026. A M18 **não cria outro checkout**. O catálogo em `PublicIndoorPricing` exibe somente planos públicos autorizados e indica `checkout_available=false` porque o clique abre **solicitação guiada não vinculante**, não pagamento imediato. O wizard `AcquisitionWizard` exige escolha de uma agência autorizada para estabelecimento/anunciante, lead consentido e idempotente, snapshot do plano/oferta publicado e UTM. `IndoorContractProgress` cria solicitação privada pré-contratual com código que permanece na memória do navegador. O Master apresenta proposta e aceita as condições; `IndoorCheckoutPanel` emite PIX via backend somente após aceite, e assinatura/serviço só ativam depois de confirmação GET do Mercado Pago. Acessos privados podem ser retomados em `/acompanhar` com código e referência, nunca em URL ou analytics.

**Ajuste real M18:** `src/lib/portal-cookie.mjs` protege a extração de cookies do Express/Portal contra UTF-8 percentual malformado, duplicações, controle e cabeçalhos grandes. O servidor não deve retornar HTTP 500 ou renovar sessão por cookie inválido; token continua exclusivamente HTTP-only, quando aplicável. `ClientOnboarding` não divide por zero com lista de etapas vazia. `scripts/test-rc10-journeys.mjs` cobre lead (agência/plano/UTM/consentimento/idempotência) e cookies inválidos; `npm run build` passa a executar o teste RC10 com as demais regressões.

**Não inventar** newsletter funcional, domínios próprios de Landing Pages, contratação automática de planos não autorizados, conferência independente de extrato ou anúncios aprovados sem direitos de veiculação. O site público só encaminha interesse; o Metronic 9.5 oficial é o único painel administrativo e o Player Web é aplicação independente.

Para pré-validação de código (não homologação): `npm ci && npm run test:rc10 && npm run lint && npm run build`, e conferir `npm run test:http` com ambiente de teste existente. Depois validar manualmente SSR SEO e entrada `/contratar` com agência e plano, confirmação do lead persistido, pedido pré-contratual, proposta, PIX sandbox e acesso privado retomado em `/acompanhar` (320–1440, duas agências, erro de rede e concorrência).
