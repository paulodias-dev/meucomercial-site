# Meu Comercial

Landing page profissional para apresentação da plataforma Meu Comercial, uma solução de TV Corporativa e Mídia Indoor em nuvem voltada para comunicação interna, sinalização digital, campanhas comerciais e gestão de conteúdo em telas.

Desenvolvido por [Fluxo Sistemas](https://fluxosistemas.com.br/), empresa especializada em engenharia de software, desenvolvimento de sistemas web de alta performance, soluções com PHP, Laravel, React, consultoria de TI, performance web, SEO e hospedagem otimizada.

## Visão Geral

O projeto combina uma experiência visual moderna com recursos interativos para demonstrar o valor da plataforma Meu Comercial. A landing page apresenta simulação de TV corporativa, benefícios comerciais, calculadora de planos, consultor estratégico por segmento e formulário para captação de leads.

## Principais Recursos

- Página responsiva com foco em conversão.
- Simulador visual de layouts para TV corporativa.
- Calculadora de planos por quantidade de telas e ciclo de cobrança.
- Consultor estratégico com planos de conteúdo por segmento.
- Formulário comercial para solicitação de demonstração.
- Seções de recursos, benefícios, depoimentos, preços e contato.

## Tecnologias

- React
- TypeScript
- Vite
- Express
- Tailwind CSS
- Framer Motion
- Lucide React

## Requisitos

- Node.js 20 ou superior
- npm

## Como Executar

Instale as dependências:

```bash
npm install
```

Inicie o ambiente de desenvolvimento:

```bash
npm run dev
```

A aplicação ficará disponível em:

```text
http://localhost:3000
```

## Scripts

- `npm run dev`: inicia o servidor de desenvolvimento.
- `npm run build`: gera a versão de produção.
- `npm run start`: executa a versão compilada.
- `npm run lint`: valida os tipos TypeScript.
- `npm run clean`: remove arquivos gerados de build.

## Estrutura

```text
src/
  App.tsx       Interface principal da landing page
  index.css     Estilos globais e configuração visual
  main.tsx      Ponto de entrada React
server.ts       Servidor Express com integração Vite e API local
index.html      Documento HTML base
```
